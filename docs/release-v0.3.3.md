# v0.3.3 大输出与可选思考模式

需求：用户需要单次最大输出 300000 tokens，并可开启 DeepSeek 思考。基线为 v0.3.2（12bfc16）。

- 前端输入和后台校验上限由 16000 同步调整为 393216；仅接受 256–393216 的整数，错误提示给出范围。300000 可以保存。该值是每次模型请求的上限，不是目标字数，也不是整课所有分批的总额度；供应商的实际模型及上下文限制仍生效。
- API 设置的文本生成区域增加“启用思考模式（DeepSeek）”。只对官方 api.deepseek.com 发送 thinking 参数，JSON 输出在两种模式中均启用。旧配置默认关闭，保存的新配置持久化，并由新任务冻结；非 DeepSeek 接口不接收专属参数。
- 思考与最终答案共用输出额度。程序只消费最终 content，不将 reasoning_content 保存或展示为笔记。设为大额度或开启思考可能增加等待时间和用量；价格及金额预算逻辑保留。
- 常规课堂任务仍以18秒为总时限（包括排队）；明确开启思考或设置大于16000的输出额度时采用30分钟总时限。后台任务继续30分钟，录音独立运行。
- 流式正文和传输容量随选定输出额度调整，保留有界内存保护。笔记主题、人工编辑和学习资料支持长内容，上限6291456字符；不会再仅因旧60K生成块/100K编辑上限拒绝长笔记。
- 流式预览最多8000字符；提取到上限后停止重复扫描，避免长答案的逐 token 预览拖慢处理。最终内容与结束原因仍完整处理。

58项核心测试包含大额度、思考字段、超2MB推理流、600K最终笔记的32字符小分片、长笔记保存/编辑、非法超限和慢生成任务截止。独立设置测试 test:generation-settings 覆盖300000与393216、非法边界、开关保存及重启恢复，不发送真实 API 请求。

用户修改 API 设置后须保存并按界面重新确认课程授权；旧任务保留原参数，因此应新建整课任务来使用新额度和思考开关。没有自动调用真实模型，也未在本轮生成300000 tokens作实测。

官方依据：[请求参数范围](https://api-docs.deepseek.com/api/create-chat-completion/)、[思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)。不改变课程数据结构或原始资料。
