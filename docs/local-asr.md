# 本地 ASR 接入说明（0.3.0）

## 使用

1. 打开“API 与设置”，选择本机离线。安装包只包含推理引擎，启动不会自动下载模型。
2. 在本地模型中选择 SenseVoiceSmall INT8（约 240 MB）或 Qwen3-ASR 0.6B INT8（约 987 MB），主动点击下载。下载和模型来源按钮均对应所选魔搭仓库；两个模型可以分别保留、切换。Windows x64 CPU 运行，不依赖 Python/CUDA。
3. Qwen3 可以填写当前课程的术语，每行一个或用逗号分隔，最多 80 个、1000 字符。术语仅作为模型提示，不把错误文本硬替换为指定知识点。没有默认填入本次课堂的专有内容。
4. 录音仍约每 5 秒保存；识别会累计最多 20 秒，在最后 8 秒内优先选择低能量停顿边界。停止、暂停及手动补转写会处理不足 20 秒的尾部。时间标记表示语句覆盖的音频范围，回听可跨文件完整播放。没有逐字时间戳、说话人分离或完整 VAD。
5. “补转写”仅处理未确认范围。“用当前模型重新转写”复制原录音到新讲次，保留原讲次的转录和笔记供比较。重新转写讲次默认半自动，不自动提交文本 AI。

## 模型来源与下载

- SenseVoice：[魔搭 ONNX 镜像](https://modelscope.cn/models/WEAAEW/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17)，原模型 iic/SenseVoiceSmall。
- Qwen3：[魔搭 ONNX 导出](https://modelscope.cn/models/zengshuishui/Qwen3-ASR-onnx)，原模型 Qwen/Qwen3-ASR-0.6B。采用其中 model_0.6B 下 conv_frontend、INT8 encoder/decoder 和 tokenizer，符合 sherpa-onnx 的 Qwen3 接口；[官方运行说明](https://k2-fsa.github.io/sherpa/onnx/qwen3-asr/pretrained.html)。这是社区导出资产，不能误称为千问官方直接发布的 ONNX 权重。
- 引擎为 sherpa-onnx-node 2.0.1，模型在独立进程串行推理，不阻塞窗口或录音保存。
- 仅下载固定名单内的兼容文件，分块请求支持失败后继续下载，并在安装前核对固定大小和 SHA-256。仓库资产发生变化会拒绝安装，需要更新兼容清单。示例测试音频来自上述 SenseVoice 仓库，测试只验证引擎运行。
- 模型默认保存在 userData/models 下 sensevoice-small-int8 或 qwen3-asr-0.6b-int8，不随课程删除。模型包、私人录音、数据库和 API 密钥不提交 Git。

## 真实课堂比较及限制

本次用保存的同一段课堂原音比较，全部在本机执行：旧 SenseVoice 的“我能用确定的时金……”在 Qwen3 配合课程术语后识别出“我能用确定性图灵机……验证这个答案是对还是错的”。NP 等部分术语改善，但“多项式时间”“非确定性图灵机”等在某些句子仍不完整或有误。Paraformer 对这段音频也没有足够改善，因此没有加入程序模型选项。

这只能说明局部改善，不能据此给出整节课准确率或宣称课堂可用已经验收。没有人工逐字真值，未计算 CER。术语提示也不能保证识别正确。实际还发现一次完整词表被复述到转录中，程序会保留原文、标记“待核对”，并阻止其自动提交笔记；人工纠错后解除。此规则只能检测完整词表复述，不能检测所有误识别或幻觉。

本机 Qwen3 20 秒音频的两次热推理约 19 秒和 20 秒；首次带加载约 51 秒。新分段策略在 Electron 中处理完整约 124 秒课堂录音约用 71 秒（一次本机观察，包含模型加载），得到 7 条长句，音频范围覆盖完整且旧内容保留。长时间课堂可能积压，应结合机器速度判断是否能满足实时需求。SenseVoice 更小更快，但本次复杂术语录音效果差。远场、混响、口音、音量及切句都可能影响结果；这些改动无法保证恢复原音中不清楚的信息。生成笔记前仍应回听核对。

## API 与构建

本地转写无需 API Key、音频上传授权，也不计入 API 调用；文本 AI 关闭时照常运行。自动整理笔记需要另外配置文本 API 并授权文字上传。

npm run build 构建界面；npm run pack 生成 release-asr-v0.3/win-unpacked。交付为免安装目录及 ZIP；模型需要使用时从魔搭下载。native .node 和 DLL 解包到 app.asar.unpacked。开发验证通过 LECTURE_DATA_DIR、LECTURE_MODEL_DIR 使用隔离目录，不能写入用户当前正在使用的课程库。
