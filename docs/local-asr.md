# 本地 ASR 接入说明（0.2.0）

## 用户流程

1. 打开 API 与设置，在本地语音识别卡片点击下载模型。安装包只包含引擎，不包含权重；应用启动不会自动下载。来源按钮打开固定的魔搭模型仓库。
2. 等待约 240 MB 文件下载完成，选择本机离线并保存语音识别设置。模型测试使用随模型下载的 5.592 秒中文示例。
3. 新建课程、课次后录音，约每 5 秒保存一个音频分段并在本机转写。导入音频同样会转写。音频先落盘，识别失败后可补转写。
4. 关闭文本 AI、没有 API Key、没有音频上传授权都可进行本地识别。需要结构化笔记时，再配置文本 API 并授权发送转录文字。

## 实现与边界

- sherpa-onnx-node 2.0.1，CPU，SenseVoiceSmall INT8，自动语言识别及逆文本规范化。Windows x64 不依赖 Python/CUDA。
- 模型仓库：WEAAEW/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17（魔搭社区 ONNX 镜像）。下载 model.int8.onnx、tokens.txt、LICENSE、test_wavs/zh.wav，合计 239,728,794 字节。保留来源与许可文件。
- 固定文件版本校验；下载进度、失败重试、临时目录、完成后安装。已完整的文件可复用，未完成的单文件重新下载。后续模型仓库内容若变化，拒绝不匹配资产，需要更新兼容版本。
- 模型保存在 userData/models/sensevoice-small-int8，随课程数据库之外持久保留。开发验收通过 LECTURE_MODEL_DIR 指定隔离模型目录。
- 推理在独立进程执行，按队列串行运行，不阻塞主窗口或录音保存。进程异常会留下原始音频供后续补转写；只对还没确认的音频范围转写，避免重复。
- 时间为分片范围，约 5 秒出一段，加模型加载/推理时间。不是逐字流式 ASR；跨片断句会影响识别质量。没有说话人分离、逐字对齐或完整 VAD。
- 初次真实 CPU 验证：5.592 秒中文样例得到“开饭时间早上9点至下午5点。”，单次纯推理约 223 ms（不含首次模型加载）。样例中“开放”误识别为“开饭”，所以功能跑通不代表课堂准确率已验收。

## 开发与打包

npm run build 构建界面，npm run pack 生成 release-local-asr/win-unpacked 免安装目录；npm run dist 用于构建 NSIS 安装器。本次交付已生成 0.2.0 免安装 ZIP。当前受限 Windows 环境下 NSIS 编译工具出现系统 DLL 重定位错误，安装器尚未生成。native .node 和 DLL 必须解包至 app.asar.unpacked。模型和开发验收缓存不在打包范围内。

scripts/verify-local-asr.cjs 是开发者主动联网验证工具，会下载到项目父目录的 .qa；应用启动不运行这个脚本。实际使用请在程序设置中按需下载。

实际集成验证：真实模型在 Electron 开发版和打包版均可识别；关闭文本 AI、无 API Key、无音频上传授权时导入音频自动转写成功；重复补转写不增加相同范围；使用样例作为模拟麦克风输入完成录音分段及停止尾部保存。打包版首次打开无模型目录、无自动下载，模型来源按钮指向上述魔搭仓库。真实课堂和物理麦克风质量仍需现场评估。
