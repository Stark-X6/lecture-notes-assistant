# 听课笔记助手需求变更与功能补齐清单

版本 v0.3　日期 2026年11月6日

本清单依据本次用户澄清、[需求分析 v0.2](听课笔记助手_需求分析文档_v0.2.md)及[功能核对记录](听课笔记助手_功能核对与试用清单_2026-11-06.md)整理，作为下一轮设计和开发的输入。当前实现核对基线为 d8e6d76；本清单中的新增、修正和补齐内容不代表软件已经实现。旧文档保留作历史依据，冲突处以本次澄清为准。

## 1 本次明确修正与新增的要求

| 编号 | 变更 | 精确含义 |
| --- | --- | --- |
| C01 | 修正自动模式 | 自动模式在课堂中录音和转录，等下课且完整转录准备好后，再交给 AI 整理；也可导入完整转录后再整理。取消当前每60秒调用笔记生成 AI 的行为。 |
| C02 | 保留半自动模式 | 课堂中由用户按知识点翻阅课件、选定相关材料并提交转录段，后台生成笔记；录音不因提交而停止。 |
| C03 | 独立课程管理页面 | 课程拥有独立的学习与管理空间，集中保存课件、教材、课程笔记等资料，可新建课堂记录、生成预习复习材料、围绕课程提问。 |
| C04 | 课程页参考 NotebookLM 布局 | 建议左侧为课程资料与来源，中间为对话，右侧为笔记及预习复习等学习产物；课堂记录使用独立入口，不与课程资料混成同一列表。 |
| C05 | 一个课程支持多个对话 | 中间对话区可新建和切换多个独立对话，保留各自历史；同一课程可分别开设预习、章节答疑、复习等对话。 |
| C06 | 课堂记录按上课时间组织 | 一条课堂记录对应一次课堂，包含日期时间、录音、转录、处理状态和关联材料；列表按课堂时间排列，而不是只按文件名或导入时间排列。 |
| C07 | 跨课堂复用课程资料与笔记 | 多节课可以选择同一个 PPT、教材及课程笔记。新建或编辑课堂时，应能从课程已保存内容中选择，避免每节课重复导入或复制。 |

其中 C04 的三栏位置和下文默认行为是建议细化；多对话、独立课程页、时间序课堂及共享资料是本次明确的目标要求。

## 2 自动与半自动模式的新定义

### 2.1 自动模式改为课后完整整理

录音与转录可以在课堂中实时进行，但不按固定60秒窗口调用笔记生成模型。自动模式的“自动”指完成材料准备后，系统统一整理整节课，不要求用户逐段提交。

支持两条入口：

1. **课堂录音入口**：开始录音与转录 → 下课结束录音 → 等待最终句子和缺口处理完毕 → 使用完整转录及关联资料执行整课整理。
2. **已有转录入口**：新建或选择课堂记录 → 导入完整 TXT/SRT 等转录 → 选择课程中的课件、教材、目标笔记和模板 → 提交整课整理。

建议默认行为：录音入口在转录完整后自动创建整课任务；导入入口由用户确认关联资料后点击“整理整课”。界面应明确显示是否启用结束后自动整理，避免产生意外调用。

“转录完整”不能仅凭停止录音或连接关闭判断：应确认录音尾部已保存、转写收尾成功、必要音频范围已处理。断网、转写失败或缺口未补齐时，停留在“待补齐”，显示缺失范围；用户明确选择使用不完整内容时，产物必须标记缺失，不能显示完整整理成功。

产品上是一次整课任务。若完整转录超过模型上下文，系统可在内部按主题分批处理并最终归并；用户不需要手动拆成多段，不能直接以“上下文过长”结束流程。分批必须保留前后关系、来源与教师后续纠正，不能只拼接几份摘要。

### 2.2 半自动模式继续用于课堂辅助

用户手动选择当前知识点、课件/教材页范围，按需要补充提示并提交本段。提交冻结本段转录、所选材料、模板和目标笔记版本，录音继续。未定稿尾部保留明确的等待或补齐状态；重复提交不能重复写入。

下课后可以处理余量，再执行整课归并。模式切换时保留已有录音、转录、任务和版本；从半自动切到自动后不再新建课堂笔记生成任务，已提交任务可继续或由用户取消。下课时基于完整转录归并，并保护已经生成及手动修改的内容。

### 2.3 需同步修订的旧条目

| 旧条目 | 本轮修订 |
| --- | --- |
| F03 自动60秒分节 | 改为课后或导入完整转录后的整课整理。60秒不再是自动模式的业务触发规则。 |
| F04 两模式均实时生成笔记 | 半自动保留课堂分节生成；自动模式在转录准备完成后生成。 |
| A02 自动60秒触发验收 | 改测课堂中不定时整理、结束且转录完整后创建任务、导入完整转录可整理、缺口不被隐瞒。 |
| N01/A07 生成时延 | 实时转录目标保留；半自动短段首批20秒目标仍可沿用。整课整理、预习复习及问答分别制定首批内容与总耗时指标，不直接套用短段的首批20秒目标。 |
| 自动模式相关说明和测试 | 同步修改界面“自动·60秒”、调度逻辑、帮助文档、测试用例与验收记录。 |

## 3 课程与课堂记录的页面及数据关系

### 3.1 课程是长期学习空间

建议入口层级为：课程总览 → 课程空间 → 课程学习或课堂记录 → 某次课堂工作区。

课程空间至少包含：课程名称与基本信息、课程资料库、课程笔记、多个对话、课堂记录时间列表、课程模板与学习产物。用户从课程页新建课堂，也能从该页查看已保存笔记、生成预习复习资料并提问。

建议课程学习页采用以下分区；资料查看可展开，面板可调节、折叠，窄窗口保持主要操作可达。

| 分区 | 主要内容 |
| --- | --- |
| 左侧资料与来源 | 课件、教材、笔记等课程资源，可选择本次对话或生成任务使用的资料及章节范围。 |
| 中间多对话区 | 对话标签或列表、新建入口、当前对话历史与输入框，支持在多个对话间切换。 |
| 右侧学习产物 | 课程笔记、预习提纲、复习资料及对应生成入口，能查看、编辑和导出。 |
| 课程级导航 | “课程学习”“课堂记录”等独立入口，以及新建课堂和课程设置。 |

这借鉴的是 NotebookLM 的 Sources、Chat、Studio 分区思路；具体布局及多对话行为按本项目需求设计。[Google 官方界面说明](https://support.google.com/gemininotebook/answer/16206563?hl=zh-Hans)

### 3.2 多个对话共享课程资料，分别保存聊天上下文

每个对话属于一门课程，建议支持新建、命名、切换和历史保存。不同对话的消息历史分别维护；切换不应丢失未发送草稿或生成状态，也不应把前一个对话的消息自动混入新对话。

同一课程资料库可供多个对话使用，每个对话记录本次选择的资料范围。问答可以引用已选资料、笔记或课堂转录，回答应定位到文件页、笔记内容或具体课堂时间；没有足够资料时说明依据不足。对话默认不引用其他课程。

建议允许将有用回答保存为课程笔记或学习资料；保存到已有笔记时仍遵守候选确认和版本保护。预习复习属于课程级能力，可以选择章节、资料或课堂范围，不必先打开某次课堂。

### 3.3 课堂记录是按时间组织的一次学习过程

课堂记录包括上课日期、开始时间、可编辑标题、录音、转录及处理状态。默认按上课时间倒序显示；导入历史转录时可填写实际上课时间，导入时间另存，不替代课堂时间。

新建课堂时，从课程资料库选择课件、教材、目标笔记及可选章节范围；也可当场上传并保存到课程资料库。进入课堂后可切换或补充所关联材料。课堂工作区保留适合录音、翻页、转录及笔记操作的四区布局，不要求把课程页的三栏对话界面原样搬进课堂。

### 3.4 多节课复用同一材料及笔记

例如，11月6日与11月13日的课堂可以共同关联“第3章课件.pdf”“教材.pdf”和“第3章笔记.md”，各自保存录音、转录及使用页范围。课程笔记可以持续吸收多节课的讲解，不必每节课生成一份互不关联的笔记。

| 对象 | 归属与关联 |
| --- | --- |
| 课件、教材等资料 | 属于课程；多条课堂记录通过关联复用，课堂各自保存使用范围。 |
| 课程笔记 | 属于课程；可关联多次课堂，支持新建笔记或追加到已有笔记。 |
| 录音与转录 | 归属具体课堂；作为课程可检索的来源时仍保留课堂日期、原时间与修订号。 |
| 对话 | 属于课程；保存独立历史和所选资料，不与课堂记录共用同一个对象。 |
| 预习复习等学习产物 | 属于课程；记录生成时的材料、章节或课堂范围。 |

浏览页与 AI 处理范围应分别保存：翻阅或点击引用不应无声改变任务范围。每次生成固定实际使用的资料版本、转录修订、模板和目标笔记基线。多课堂更新同一笔记时要检查版本，避免相互覆盖；新增课堂补充保留原有正确内容、个人批注和各课来源。

删除课堂记录前应说明录音、转录及引用影响；课程共享资料和共享笔记独立管理，不能随一条课堂记录级联删除。现有课堂级笔记迁入课程资料体系时，需要保留内容、历史和原课堂关联。

## 4 此前检查发现的功能缺口

以下来自 d8e6d76 的源码与隔离检查。它们与本次新增需求一起形成待补齐清单。

| 编号 | 缺口 | 补齐要求 |
| --- | --- | --- |
| G01 | 缺少独立的课件主题结构处理 | 从选定课件建立章节、主题与父子层级；支持多页同主题合并、独立主题保留及人工修正。自动整理应覆盖本次课堂关联范围。 |
| G02 | 教材融合依赖手动选页 | 在用户选定的课程资料及章节范围内检索对应知识点，提供真实页码；当前显示页仅作定位线索，不成为唯一资料来源。 |
| G03 | 长课整理由于上下文上限直接失败 | 产品上支持完整课堂任务；内部自动分批与最终归并，显示进度并支持部分失败重试。 |
| G04 | 图片只显示占位文字，本地附件导入导出被拒绝 | 支持受管本地图片、Markdown 相对附件迁移、预览和导出；已有图片链接可保留，缺失附件明确报告。 |
| G05 | 公式在应用内显示原始标记 | 阅读与预览支持行内、块级数学公式，编辑与导出保留可编辑的公式文本。 |
| G06 | 回听只播放起点所在的单一分片 | 按转录时间连续播放所需音频，跨约5秒块不中断，可定位、暂停和停止。 |
| G07 | 模板预览和旧笔记迁移范围不够精确 | 可选一个代表主题预览；可选已有笔记或主题范围生成模板迁移候选，确认前不改原文，范围外不变。图片规则与实际能力一致。 |
| G08 | 四区没有折叠展开入口 | 补齐面板折叠、展开、尺寸调整和布局保存，保持录音状态及停止入口可见。 |
| G09 | 调用次数不能代表真实费用 | 将次数限制与金额预算分别展示；完善服务用量、价格配置、估算及额度暂停，未知费用不冒充已受金额上限保护。 |
| G10 | 重点和引用的事实质量未验收 | 用真实材料检查教师明确强调、推断重点、考试要求和待核实的区别；引用存在性与内容支持关系分别验证。 |
| G11 | 可靠性与真实性能验证不足 | 补90分钟录音、断网、设备移除、磁盘满及写盘卡顿测试；明确写盘确认超时的监测与停止路径，验证恢复与去重。 |
| G12 | 部分模板和编辑选项仅靠模型遵循 | 逐项验证编号、详略、分点、重点样式和来源格式的实际呈现；用户设置应在生成、预览与导出中含义一致。 |

另需验证课程共享笔记下的并发更新、取消后迟到结果、删除课堂时共享资源保留，以及历史数据迁移。此前35项测试通过的结果继续保留，但不能代替新流程与真实课程验收。

## 5 功能范围与建议实施顺序

| 范围 | 本轮定位 |
| --- | --- |
| C01～C07 | 本次明确修正或新增的产品目标，需要纳入新版需求及设计；其中布局细节保留可调整空间。 |
| G01～G08、G12 | 直接影响笔记整理、阅读与资料复用的功能补齐项。 |
| G09～G11 | 成本、质量、可靠性及性能的补齐与验收项。 |
| F14、F16 | 预习复习与知识问答本次被再次明确提出，应纳入课程空间目标，不再仅作为泛泛远景。 |
| F11、F12、F13、F15 | 教材骨架切换、AI找页、板书与卡片测验仍保留为既有扩展，不能因当前未实现而从总清单移除。具体开发批次另定。 |

建议实施顺序为：

1. 修正自动/半自动模式及完整转录就绪判断，同时补长课任务能力。
2. 建立课程级资料与笔记、课堂时间列表及关联选择，迁移现有数据。
3. 建立独立课程页与多对话，接入基于课程资料的问答、预习和复习生成。
4. 补齐主题组织、教材检索、图片公式、连续回听及模板范围操作，贯通新页面。
5. 按新版验收验证共享资源、内容质量、故障恢复、性能和费用，再安排其余扩展。

以上顺序是建议，并非已确认的工期或开发承诺；可以调整批次，但不应把本次明确提出的需求遗漏回旧版清单。

## 6 代表性验收场景

| 场景 | 通过条件 |
| --- | --- |
| 自动模式录制一节课 | 课堂中不每60秒生成笔记；结束后等待转录完整，只创建一次整课用户任务；存在缺口时可见且不显示完整完成。 |
| 导入完整转录 | 选择课堂日期及课程已有资料、模板和目标笔记后可整理；超上下文时后台分批，用户不必手拆。 |
| 半自动课堂 | 按三个知识点连续提交，录音继续，范围与来源可核对；下课余量可处理，整课归并不重复堆叠。 |
| 两节课共用资料 | 两次课堂引用同一份 PPT、教材和笔记，使用页范围分别保存；不产生不必要文件副本。 |
| 两节课更新同一笔记 | 第二节补充进入原笔记相应主题，保留第一节内容、来源和人工修改；基线冲突产生候选。 |
| 课程多对话 | 切换章节答疑、预习和复习对话，历史、草稿与所选资料分别保留，消息上下文不串用。 |
| 课程页生成学习资料 | 不进入课堂工作区也能选资料、章节或课堂范围，生成有来源的预习复习资料并保存。 |
| 阅读与导出 | 图片可见，公式排版正确，附件相对路径可用；跨音频块回听连续，外部 Markdown 编辑器能使用导出结果。 |
| 删除或迁移课堂 | 删除单次课堂不会误删课程共享资料与笔记；迁移原有数据后版本、来源和课堂关联仍有效。 |

下一轮设计应同时更新页面导航、课程/课堂/资料/笔记/对话关系、AI处理流程与验收矩阵，避免只增加几个按钮而继续沿用旧的课堂级数据结构。
