# v0.4 界面与转录范围交互

需求来自用户本轮反馈：整理按钮过小、逐条时间戳与归类操作繁琐、当前紫蓝配色与课程页缺少辨识度。用户已选择纸白、墨黑、苔绿。基线2cd35bd，沿用 Electron / React / TypeScript，不增加框架、外部字体或云端服务。

采用 Anthropic 官方 frontend-design 指导：https://github.com/anthropics/skills/tree/main/skills/frontend-design 。仅作为设计方法，不引入运行时 Skill 或依赖。

## 视觉与布局

颜色：纸白#f5f4ef，表面#fffefb，墨黑#263029，苔绿#43614d，次要文字#657064，分隔#d9ded3。标题使用本机宋体/衬线字体（Songti SC / SimSun / serif），正文使用系统中文无衬线，数字采用等宽排版。对齐以左对齐为主，字号以13–14px正文和28px课程标题形成层级。

课程页保留原资料、对话、笔记三栏，以中间对话为主栏，左侧资料目录，右侧笔记与学习资料。用结构化标题、细线和适度留白替代同质圆角卡片堆叠；保留多对话切换与草稿，课程独立课堂记录。窄窗口允许重新排列而不裁掉操作。

课堂页顶部提供唯一的主操作“整理课堂笔记”（至少44px高），关联当前整课转录、课件教材范围和提示。转录面板中的分段整理保留，但改为明确的“整理所选内容”/“整理待处理内容”；自动模式仍提示切换半自动才可分段整理，不改变录音或课后自动整理语义。

## 转录范围

- 时间输入支持秒、分:秒、时:分:秒，可含毫秒；非负，秒/分进位字段<60。按区间[开始,结束)选择与其重叠的完整定稿段落，不切割源句，不编造逐字时间；零时长段落视为一个时间点。边界语义在范围控件附近说明。
- 有时间戳的SRT默认按时间选择，可一次选择全部。无时间戳TXT默认按原始段落序号范围选择，明确提示无时间戳；混合来源允许切到段落选择，未定稿内容不纳入选择。
- 搜索仅影响显示，范围选择针对本课堂完整列表，并显示已选数量以及搜索之外的已选数量。修改输入不会立即改变已应用选择，须点“选择范围”；无效范围或没有匹配段落给明确提示，且不覆盖原选择。
- 选定范围后沿用已有批量主题归属接口，一次归入一个主题；保留逐句展开、纠错和回听入口。归属不直接生成笔记。分段提交只传选中的原始ID，整课按钮始终处理整课，不受局部选择影响。
- 转录默认以约一分钟的阅读段落显示时间范围，按已有主题变化分组；不为每句重复展示时间、状态、复选框。逐句详情按需展开。原始ID、文本、时间、引用跳转保持有效，不变更持久数据模型。

## 验证与边界

测试时间格式与精度、跨小时、相交/相邻边界、零时长、未定稿排除、无时间戳段落范围；测试一次范围批量归属与原始ID保留、搜索不改变范围、分段只提交所选内容、整课提交不受选择影响、切换课堂清空选择。验证已有课程聊天草稿、模板、引用、手工编辑保护、录音和模型设置流程。

对1500x970与1050x720视口截图检查按钮可见、触达尺寸、键盘焦点、对比度、滚动与长文件名。构建macOS应用并替换原启动路径前确认没有录音/任务；不自动提交个人课堂内容。Windows代码与打包支持保留，本机不能代替Windows运行验收。细节排版和组件拆分交给实现者合理决定。


## 实现补充

范围输入以可收起的视口浮层呈现，选择后收起；窄面板不裁掉控件，Esc和外部点击可关闭。右侧转录面板设280px最小高度，保留完整提交区。实时半自动在新语音尚未定稿时仍可提交边界，显示等待转写补齐；录音和全课整理语义保持。

课程导航均沿用保存草稿后再切换的流程，保存失败时保留编辑器及草稿。阅读分组只改变呈现，原始句ID可用于纠错、回听与来源跳转；段落编号按原始导入顺序。内部generated-sources标记在阅读时隐藏，导出和数据保持原样。

版本0.4.0。62项核心测试，加独立界面测试覆盖范围、搜索、批量主题、分段/整课、课堂隔离、拖拽最小高度、160px小面板浮层、实时待定稿提交及保存失败导航。截图使用隔离测试数据；不自动向云端提交个人课堂。

课程页旧的失败任务默认收起在可展开记录中；出现进行中的任务时自动展开，失败后保留可见反馈，不移除重试入口。
