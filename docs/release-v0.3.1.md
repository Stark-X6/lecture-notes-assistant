# v0.3.1 课程空间版

## 验证结果与边界

本轮新增12项回归，加上指定分支原有34项，共46项通过。旧文档中“35项”的口径保留在历史记录；本次以实际 `node --test` 输出为准。TypeScript/Vite构建通过；旧课堂桌面流程和新课程空间桌面流程通过。

加速音频测试写入90分钟等效24kHz单声道PCM，1080个5秒WAV，共259,247,520字节，验证时间连续和头部长度；在本机一次运行耗时约3.5秒。该结果仅验证分片写盘容量和时间映射，**不是90分钟实时录制、真实ASR延迟或真实麦克风测试**。

未使用真实供应商API密钥。模拟内容仅证明调用、版本、界面流程，不证明事实正确、引用语义支持、实际费用或时延达标。模型分批后主题归并仍需真实课程检查教师后续纠正、来源覆盖与语义去重。

## 数据升级与回退

首次打开旧schema数据库会先保存 `app.pre-v03.db`，再迁移到schema 3。每个旧课堂先迁为独立课程笔记，不自动把不同课堂的内容混合；用户可在“课堂日期与共享资料”中让后续课堂关联已有笔记。旧topic/revision/candidate ID不变。

回退前先退出程序并备份整个应用资料目录。恢复旧程序时同时恢复迁移前数据库；不要让旧程序写入已升级的数据库。单次课堂删除采用回收状态，不清理共享笔记、资料和历史引用；课程删除仍是原有确认后清理本机课程数据的操作。
