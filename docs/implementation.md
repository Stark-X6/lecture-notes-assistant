# 系统设计与实现 v0.9.1

学生从课程空间进入按上课时间排列的课堂记录。每节课堂关联本课程的课件、可选教材与目标笔记本。课堂工作区使用四个固定标签，同一次录音、转录与整理任务可跨标签继续。课程和课堂的基础要求见 [需求变更清单](requirements-v0.3.md)。

## 架构与数据关系

React 主窗口渲染课程空间或课堂标签，预加载层暴露具名 IPC。Electron 主进程校验窗口、主框架与方法，再访问资料、课程状态或队列。独立录音窗口每约 100 毫秒发送一帧，后台线程约每 5 秒封存一个 24 kHz、16 bit 单声道 WAV 块。写盘与识别分别推进。sql.js 将状态以快照方式原子保存到本机 SQLite，音频、材料和附件分开保存。

| 对象 | 归属与关联 |
| --- | --- |
| course、material | 课程保存模板及文字/音频授权。材料由 courseId、文件哈希、分页文本与章节提纲标识。 |
| notebook、topic | 一本课程笔记可供多节课选择。主题关联 noteId、父主题、正文、版本、人工标记与来源。历史 lessonId 表示主题出处。 |
| lesson | 保存 courseId、noteId、startedAt、资料范围、录音状态和整理就绪条件。 |
| utterance、chunk、stream | 属于具体课堂，记录整课时间、转录修订、流起点与已确认区间。 |
| conversation、artifact | 按课程保存独立对话、草稿、范围、预习复习产物及历史。 |
| task、candidate、revision | 冻结输入、幂等键、检查点与主题版本，保留候选和旧版正文及来源。 |

早期数据库升级前备份为 app.pre-v03.db。旧课的笔记迁为课程笔记，保留主题、历史、候选与来源。删除单次课堂采用软删除。删除整门课程需确认名称。早期课程存储的面板比例与折叠值不参与课堂标签渲染。

## 课堂导航与来源定位

课堂按“课件、教材、笔记、转录”排列四个常驻标签，首次进入课次时默认课件，同一应用会话记住各课次最近使用的标签。每次展示一个正文视图，其余页保持挂载。左右方向键、Home 与 End 可在标签栏导航。共享录音控件、状态和时长在标签外。来回切换时两份材料各自保留页码、缩放和阅读位置，笔记保留当前主题和编辑状态，转录保留搜索与选段。切换课次应隔离两个课堂的选择。

点击笔记来源时按来源角色和受管材料 ID 打开课件或教材标签，并定位原页。引用来自另一份课程材料时，也只改变阅读对象。课件选页、教材关联和已经排队的任务仍使用原设置。转录来源打开原课的转录标签并定位相应段落。原句经过文字修订时，页面并列展示引用时保存的原话和当前转录，分别标注可用版本号。跨课堂跳转前先保存当前笔记，保存失败保留原课与草稿。具有音频和有效时间范围的段落可跨 WAV 块回听。

## 整理模式与证据范围

自动模式在课堂中录音和转录。开启“结束后自动整理”时，设备尾帧、写盘、识别收尾、音频覆盖和待核对句检查通过后创建一次整课任务。导入 TXT/SRT 后可选材料并手动整理。存在缺口时显示待补齐，明确选择继续后成稿保留不完整原因。

半自动模式可按原始转录 ID 整理所选内容，或按当前录音边界提交讲解。系统冻结切点、材料、模板、笔记和主题基准，尾句未定稿时登记等待。模式切换只影响之后的提交。

未建立整章骨架时，课堂整理用课件选页界定主题。有关联课件时，每个笔记块均须引用至少一页所选课件。程序用这些页的文字在关联教材全书检索，匹配有共同用词的章节编号，并结合正文词项，避开目录等非正文。命中的教材摘录保留真实页码。选择教材作为结构时，按命中的教材页与章节安排笔记，课件证据约束仍生效。只有教材时，以本课讲解检索，可选择按教材或课堂讲解组织。选页无文字或教材结构找不到匹配时，向用户说明原因。材料阅读位置与生成范围各自独立。

选页整课任务在本地核对开场与正文。只有所选课件带有编号章纲，且前半节转录中先出现总结章纲、随后明确转入正文的连贯表述，才判断开场边界。某主题引用的转录全部来自开场，或它对应章纲标题且所引开场段占多数时，主题正文和来源收入任务详情的“开场导读”。其余主题仍按原流程生成笔记或候选。没有明确转场时保留正常笔记路径。对于带“教师强调”标记的文字，会检查所引原句是否带强调措辞，无法支持时降为课堂讲解或整理提示。语音误识别、短句归因和图像含义仍需对照原材料。

## 整章骨架与分批补充

由 notebook.outlineDraft 在课程范围内冻结一本主资料的版本和实际页范围。大纲任务生成带父项、标题、起止页的预览。生成预览与写入笔记分开；用户可调整层级和页范围。notebook.outlineApply 校验资料与骨架版本后，在同一事务中保存笔记的 outline 绑定及按顺序排列的小节 ID。每个小节保留 parentId 和主资料定位。已有笔记可逐本启用，历史正文、批注和来源继续保存在原笔记中。

notebook.supplement 只接收明确选中的材料页、定稿转录和可选目标。课堂里的分段、整课和等待转录完成的录音窗口复用该流程。小节目录和实际写入目标由任务冻结，发送给模型的是标题路径、本批新增证据与所需参考摘录。响应必须指向允许的小节，并引用本批证据。背景参考页不能独立产生正文。无法归类时记录未匹配，保留输入供重新选段或指定小节。

任务按笔记、骨架版本、目标及来源修订去重。相交的批次可继续处理未匹配的输入。同一小节的多份追加候选可以分别确认，采用时读取最新正文、合并来源并写入新版本。任务运行期间骨架改变会使旧补充失效；材料或模型错误也不会写入部分章节。旧笔记继续支持原有的一步整理。

## 调度、合入与模板

课堂短任务并发 2，后台任务并发 1。普通短任务截止时间为 18 秒，计入排队。启用思考或输出额度超过 16,000 tokens 时适用 30 分钟时限。后台任务最长 30 分钟。整课对应一次用户任务，内部可分批校验输入和结果、保存检查点，在上下文受限时缩小批次。超时、输出截断或额度不足保留原笔记，失败任务可在允许条件下重试。

幂等键覆盖转录修订、材料及页码、模板、提供商配置、目标笔记和基准。按课件/教材结构生成时，已有章节标题可作归属线索，旧笔记正文与旧课来源留在本机。模型请求用短标识区分课件、教材与转录，返回后映射回原始材料页和转录修订 ID，再按冻结来源校验。新讲解合入对应章节，保留已有正文、附件和不同课次的来源。整课、人工编辑、来源变化或版本竞争产生候选，采用时再次检查版本。取消任务后丢弃迟到结果。

模板可从默认规则、偏好或样例起草，支持代表主题预览、独立复制、选定范围迁移。编号、项目符号、重点标签及来源格式统一呈现。公式用 KaTeX 显示，导出保留标记。受管附件使用相对路径，缺失资源明确报告。来源 ID 校验可以证明出处存在，语义是否支持结论须核对原文。

## 笔记整理如何执行

应用内置了两种模型指令。骨架指令规定标题、父子关系与来源页的返回格式。增补指令让模型在已确认的小节中选择归属，结合本批证据撰写新增 Markdown。课程模板可以调整详略和排版。运行时通过应用代码和所选文本接口执行，安装应用的机器无需安装 Codex 的 course-note-refiner 技能。

真正约束范围的是主进程。骨架任务只读取用户指定的主资料和页段，程序校验返回的标题树、页码和资料版本，然后为确认过的小节分配稳定 ID。追加任务只发送本批材料、允许写入的小节标题路径和必要参考页。T、S、B、H 等短标识在本次请求内指向具体转录修订、课件页、教材页和目标小节。响应必须是合规 JSON。程序将标识还原，验证小节归属和证据，合并新来源并按版本追加。人工修改或并发冲突可进入候选。引用存在和范围合法由程序校验，一句话在语义上是否准确仍需对照资料。

协议适配发生在提示与证据选好之后。OpenAI 原生发送 Responses 请求，Anthropic 使用 Messages，DeepSeek 和兼容服务使用 Chat Completions。原生提供商使用任务对应的 JSON Schema。流式事件在主进程转换成正文、结束状态和用量，三条路径共用同一章内写入校验。保存配置会刷新授权版本，排队任务按其冻结的提供商和来源读取密钥。

## 主要接口

| 接口 | 作用 |
| --- | --- |
| lesson.create / update / context / delete | 新建课次，选择共享笔记与材料，校验同课程归属，软删除课堂。 |
| recording.start / pause / resume / stop | 控制独立录音会话，通知时钟、收尾与状态。 |
| material.import / read / index、topic.structure | 导入受管资料，分页索引及主题父子关系校验。 |
| submission.create、task.retry / cancel | 选段、整课、显式允许不完整内容，或重试、取消。 |
| notebook.outlineDraft / outlineApply | 按主资料的整章页范围生成可编辑预览，确认时绑定笔记及稳定小节 ID。 |
| notebook.supplement | 按明确选择的材料页或转录修订生成增量；局部候选采用时追加到当前章内小节。 |
| notebook.create、note.save / restore、candidate.apply | 按主题基准版本保存，采用候选或恢复历史。 |
| conversation.save、study.generate、note.saveAnswer、artifact.save | 课程对话、问答、预习复习及回答归入笔记。 |

| attachment.import / read、budget.save | 受管位图与文本输入/输出单价、币种、金额预算。 |

## 识别、预算与可靠性

本地可选 SenseVoice、Qwen3-ASR，模型需安装，按约 12 至 20 秒分段识别。云端路径使用通用 WSS、通义听悟或 DeepSeek 分段语音识别，分别要求对应配置与课程音频授权。文本模型使用所选提供商的接口，经课程文字授权才可发送。系统加密存储凭据，密钥仅在主进程使用。

文本请求按输入和输出上限预留金额，返回用量及价格后结算，未知用量标明估算。填有预算却缺单价时暂停文本调用。课程调用次数和 ASR 费用与文本预算分开。约 5 秒 WAV 原子写入，暂停/结束收尾。有至少 5 秒待存且 15 秒无写盘确认时停止采集。重启按完整块恢复，补转写按确认范围去重。

普通操作、真实课堂内容、云端首字幕与整课时延需记录实际条件。历史要求、各版本的验证结果与平台范围见 [验收记录](acceptance.md)、[v0.3.1 发布说明](release-v0.3.1.md)及[早期实现](history/implementation-v02.md)。
