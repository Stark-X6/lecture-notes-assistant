# 系统设计与实现 v0.3.1

需求基线：[v0.3清单](requirements-v0.3.md)。开发起点：460cad1。保留指定分支本地ASR、通义听悟、通用语音及文本适配器。角色为学生使用者、本机配置维护者，不增加教师后台。

## 架构与备选方案

Electron主进程负责存储、IPC授权和异步队列；React分别渲染课程空间与课堂四区；隐藏录音窗口采集100ms音频帧，实时推流与写盘Worker并行；sql.js将结构化状态快照原子保存到SQLite，音频/材料/附件单独保存。

不选纯网页：本地模型、持续录音落盘与恢复更适合桌面端。不选远程数据库：单用户、本地优先，无账号同步需求。不选每课复制教材笔记：课程资源引用避免副本漂移。不选统一串行AI队列：课堂短段和背景整课分开调度。

## 导航与关系

课程总览→课程空间（资料/多对话/学习产物），或课堂记录（按startedAt倒序）→课堂四区。导航保持录音状态和停止入口。浏览页与AI范围分别保存，点击引用不改变任务范围。

| 对象                    | 归属与关联                                                                      |
| ----------------------- | ------------------------------------------------------------------------------- |
| course                  | 名称、模板、授权、布局                                                          |
| material                | courseId、文件哈希、页文本、outline主题层级                                     |
| notebook/topic          | courseId/noteId、父主题、body/version、人工标记、来源；topic.lessonId仅历史来源 |
| lesson                  | courseId/noteId、startedAt、createdAt/importedAt、资料范围、录音与就绪状态      |
| utterance/chunk/stream  | 属于课堂；整课时间、转录修订、stream.originMs与confirmed范围                    |
| conversation            | courseId、独立messages/draft/scope；任务按conversationId关联                    |
| artifact                | courseId、body/version/history与生成来源                                        |
| task/candidate/revision | 冻结输入、幂等键、检查点、CAS基线、追加历史                                     |

schema升级先备份app.pre-v03.db，每节旧课迁为对应课程笔记，主题/历史/候选ID保留。用户可让后续课堂关联已有笔记。单课软删除保留录音和来源，不级联删除共享资料；整门课程删除仍须名称确认。

## 自动与半自动

自动模式不创建60秒笔记任务。停止后确认设备尾帧、Worker落盘、ASR收尾、磁盘与识别范围覆盖、未定稿和待核对句子，全部满足才创建整课任务。autoAfterStop为可见开关；autoPending创建成功后清除，避免轮询重复生成。导入TXT/SRT后选择资料再手动整理。

缺口不会被文字数量掩盖；未完整时只能通过单独确认入口继续，生成正文标记不完整及原因。半自动提交冻结切点、资料范围、模板和主题基线，尾句登记waiting，确认后入live队列，录音继续。live截止18秒从原提交时间算，包含等待和排队；ASR太慢时明确超时并支持重试。切换模式保留记录和已经提交的任务。

## 任务、长课与保护

live并发2，background并发1。后台硬截止30分钟，含排队。整课是一次用户任务，内部按18K字符来源分批，带前序重叠；验证后保存检查点，按现有主题ID/新主题名称归组，再逐主题归并已有内容与后续纠正。遇到模型上下文拒绝时自动缩批；失败重试复用完成检查点。极小上下文、超大既有单主题、供应商故障或额度仍可能失败，不宣称任意模型均可完成任意长度。

幂等键包含转录修订、材料内容/页码、模板、提供商版本、目标课程笔记和主题基线。原任务重试复用冻结输入；重新生成使用当前版本。人工编辑、来源变化、跨课竞争或整课重排产生候选；采用候选必须同时匹配当前版本与候选基线。取消后迟到结果拒绝写入。

| ---------------------------------------------- | ------------------------------------------------ |
| lesson.create/update/context/delete            | 课堂日期、目标笔记、材料范围；同课程校验；软删除 |
| notebook.create / note.create/save/restore     | 课程笔记、主题与版本CAS                          |
| conversation.save / study.generate             | 独立名称/草稿/历史/范围；问答、预习、复习        |
| note.saveAnswer / artifact.save / study.export | 保存回答、追加候选、学习资料编辑和导出           |

| submission.create                              | 半自动或整课；allowIncomplete必须显式选择        |
| template.draft/preview/migrate                 | 复用文本生成；代表主题预览；指定主题迁移候选     |

| budget.save                                    | 输入/输出单价、币种、累计文本预算                |

IPC只允许主窗口主frame和白名单方法。密钥由Windows账户加密，不返回快照。Markdown附件迁移只接受文档目录内真实路径，拒绝越界和SVG等可执行格式。受管附件导出为相对路径，缺失明确报告。公式使用remark-math与rehype-katex，保留原始文本；外部图片链接保留，默认不联网加载。

## 来源、模板、预算

教材检索在用户选定章节内按中英文词项匹配，保留真实页码；整课处理全部选页。outline随输入提供主题结构。问答限定本课程来源，历史用于对话上下文，不作为事实证据。

来源ID须在冻结白名单中，界面可展开原文/页码/时间；这仅验证存在性，不证明语义支持。编号、项目符号、重点标签和来源格式经统一函数呈现；详略和按需插图属于模型指令，不能靠截断事实伪造达标。

调用次数与金额分开。文本请求按UTF-8字节上界和maxOutput预留，usage返回且价格已知时结算；未知用量保留估算并标记。有预算缺单价时暂停文本调用。ASR费用不在文本预算内，界面明确说明。

## 可靠性、性能与需求变更

5秒WAV原子写入，暂停/停止flush尾部。存在至少5秒待存音频且15秒无写盘确认则停止；flush确认5秒超时标记待补齐，设备错误同样停止。恢复按文件序号/时间重建，补转写按confirmed范围去重。

C01/C02修正旧F03/F04及A02；C03—C07新增课程空间与共享关系；F14/F16本轮实现。未改变录音独立性、版本保护、显式授权与本地优先。F11/F12/F13/F15保留扩展。目标：云端首字幕5秒、半自动首批20秒；本地ASR12—20秒语段不等于云端5秒；问答首批20秒/总120秒、整课和学习资料首批60秒/总30分钟作为真实验收目标，后台当前统一硬截止30分钟。目标尚未用真实API计时验收。
