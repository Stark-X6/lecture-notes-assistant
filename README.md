# 听课笔记助手 Windows 桌面版

本分支为 **v0.3.0 本地 ASR + 通义听悟版本**，基于仓库 master 创建。仓库提交源码、依赖锁文件和说明文档；本地模型、课程数据库、录音、API 密钥、依赖目录和 Windows 安装包均不提交。模型通过程序设置页从魔搭按需下载。已按 origin/通义听悟 的 README 合入听悟任务 API、实时字幕与补转写。

当前版本 **0.3.0（本地 ASR + 通义听悟）**。这是依据《听课笔记助手系统设计书 v1.0》和本次设计评审意见实现的桌面试用版。课程、材料、音频、转录和笔记保存在本机；语音可在本机 CPU 离线识别，也可主动选择阿里云通义听悟；本地模型从魔搭按需下载；笔记整理等文本 AI 通过用户配置的 API 调用。未提供真实供应商账户与密钥，不能将模拟测试视为真实模型内容、费用或延迟验收。

## 安装与启动

本次交付为免安装版，主程序位于 `release-asr-v0.3/win-unpacked/听课笔记助手.exe`，完整 ZIP 在项目父目录 `听课笔记助手_v0.3.0_本地ASR与听悟_免安装版.zip`。解压后必须保留整个目录。当前受限 Windows 环境的 NSIS 编译工具存在系统 DLL 重定位问题，本次提供免安装 ZIP，NSIS 安装器尚未生成；不要使用旧的 0.1.0 安装器来体验本地 ASR。构建未使用商业代码签名证书。

开发环境要求 Windows 10/11 x64、Node.js 22.12 及以上：

```powershell
npm ci
node node_modules/electron/install.js
npm start
```

首次启动可创建课程，或主动打开标明用途的示例课程。录音默认使用 Windows 默认麦克风；切换设备请先在系统设置中修改默认输入设备。系统回环收音、板书、OCR、自动找页、卡片、问答不在此版实现范围。

## 本地语音识别（不需要 API Key）

打开 **API 与设置 → 本地语音识别**，点击 **下载模型**。仅在你点击时联网从魔搭社区下载所选模型（SenseVoice 约 240 MB，Qwen3-ASR 0.6B 约 987 MB），安装包不包含模型，也不会在启动时自动下载。下载成功后选择 **本机离线 → 保存语音识别设置**，点击 **测试本地模型** 可查看真实识别结果。Windows x64 使用 sherpa-onnx，支持 SenseVoiceSmall INT8 和 Qwen3-ASR 0.6B INT8，在 CPU 运行，不需安装 Python 或 CUDA。

随后录音会按约 5 秒保存，识别累计约 12～20 秒并优先选择停顿边界；停止或暂停会处理尾部；导入 MP3/WAV 也会自动转写。识别失败或中途暂停时保留原始音频，可点 **补转写** 继续未确认的范围。模型下载失败可重试；已完整下载的文件会复用，未完成文件会从已下载位置继续。

本地语音识别和文本 AI 模式独立。**关闭文本 AI 时仍可本地转写**；自动生成结构化笔记需要另行配置文本 API 并授权发送转录文字。纯本地转写不需要音频上传授权，不消耗 API 调用次数。旧版本用户保留原云端选择，可主动切换本机离线。

模型来源为 [魔搭社区 ONNX 仓库](https://modelscope.cn/models/WEAAEW/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17)，是 [iic/SenseVoiceSmall](https://modelscope.cn/models/iic/SenseVoiceSmall) 的社区 ONNX 镜像；原生推理使用 [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx)。模型目录可在设置中查看、打开，默认位于应用 userData 下 models/sensevoice-small-int8。

Qwen3 可填写课程术语提示，并用当前模型复制原录音到新讲次重新转写。实际课堂对比有局部改善，但复杂术语仍有错误。此版是分段识别，时间戳标记整段语句；不提供逐字时间戳或说话人分离。静音过滤仅排除接近全零的片段，不等于完善的语音活动检测。课堂噪声、远场和术语仍需真实录音评估。更多说明见 [本地 ASR 接入说明](docs/local-asr.md)。

## 通义听悟使用步骤

1. **开通服务**：在 [通义听悟控制台](https://nls-portal.console.aliyun.com/) 开通“实时记录”，进入“我的项目”创建项目并取得 **AppKey**。回调方式可以选择“不设置回调主动轮询”。账户准备见 [阿里云快速入门](https://help.aliyun.com/zh/tingwu/getting-started-1)。
2. **准备访问凭据**：取得有听悟调用权限的 **AccessKey ID** 和 **AccessKey Secret**，推荐使用专用 RAM 用户。涉及权限为 `tingwu:CreateTask`、`tingwu:GetTaskInfo`；AppKey 所属项目须允许该身份访问。这里填写阿里云 AK，并非百炼的 `sk-…` 密钥。
3. **创建课堂**：启动应用，新建课程和课次。首次体验也可打开标明用途的示例课程。
4. **保存听悟配置**：停止录音，打开左下角 **API 与设置**，先将语音识别切换为 **云端** 并保存，再将工作模式选择 **真实 API**，语音提供商选择 **阿里云 · 通义听悟**，填写 AppKey、AccessKey ID、AccessKey Secret，选择中文或中英文自由说等语种，点击 **保存 API 配置**。听悟端点由应用配置，无需填写 WSS 地址或转录模型 ID。
5. **授权当前课程**：保存配置后，勾选 **允许发送麦克风音频与本课待补转写分片**，点击 **保存课程授权**。更改提供商配置后须重新授权。
6. **测试并录音**：可点击 **测试听悟鉴权（可能计费）**，确认测试任务成功创建并结束；随后关闭设置并点击 **开始录音**。临时字幕会不断更新，完整句子进入“课堂转录”。鉴权测试不发送录音，实际转写效果通过录音验证。
7. **生成笔记**：需要 AI 笔记时，再配置“文本生成”的 Chat Completions 兼容 HTTPS 地址、模型名称及文本 API 密钥，保存配置并重新保存课程的音频与文本授权。半自动点击 **提交本段**，或切换 **自动 · 60秒**。本次接入使用听悟转写能力，结构化笔记仍由独立文本服务生成。
8. **重新比较原录音**：已有本地转录时，可选择“重新转写原录音”，确认将录音发送到当前云端语音服务；程序创建新讲次并保留原转录和笔记，可能产生服务费用。
9. **暂停、结束与补转写**：暂停会结束当前听悟任务，继续录音时创建新任务。断线时音频仍保存在本机；停止本课录音后点击底部 **补转写**，按原音频时长补发未确认范围。补转写无需 OSS，期间请保持应用打开。

密钥只在应用设置中填写，由 Windows 账户加密保存。云端任务结束失败时，进入设置点击 **重试结束云端任务**。更换听悟项目、凭据或删除课程前，先处理遗留任务。完整说明见 [听悟接入与使用说明](docs/tingwu-integration.md)。

常见情况：

| 现象                          | 处理方法                                                                         |
| ----------------------------- | -------------------------------------------------------------------------------- |
| 应用仍显示模拟模式            | 工作模式改为“真实 API”，保存配置并重新授权课程                                   |
| 提示无音频授权                | 保存当前课程的音频授权；每次更改 API 配置后重新授权                              |
| 鉴权失败                      | 检查实时记录服务是否开通，AppKey、AK ID、AK Secret 是否对应，以及 RAM 权限和网络 |
| 有转录但没有 AI 笔记          | 配置文本生成服务并保存课程文本授权，再提交本段或开启自动整理                     |
| 断网后缺少转录                | 停止本课录音后点击“补转写”；处理速度约为音频原速                                 |
| `npm ci` 或 Electron 下载失败 | 检查 npm/GitHub 下载网络，恢复后重新执行安装命令                                 |

## API 接入

打开左下角 **API 与设置**，工作模式选择“真实 API”，分别填写以下信息。密钥在应用内输入，不要写到源码、README 或聊天里。

| 能力                     | 当前支持协议                                                 | 需要填写                                     |
| ------------------------ | ------------------------------------------------------------ | -------------------------------------------- |
| 笔记整理、模板起草与预览 | Chat Completions 兼容 HTTP；支持 SSE 或 JSON 响应            | 完整 HTTPS 端点、模型 ID、文本密钥           |
| 麦克风实时转录           | OpenAI Realtime transcription 事件协议；24 kHz 单声道 PCM16  | 完整 WSS 端点、转录模型 ID、语音密钥         |
| 断线音频补转写           | OpenAI 兼容 multipart 文件转写接口，返回 `{ "text": "..." }` | 完整 HTTPS 文件转写端点、模型 ID、语音密钥   |
| 阿里云通义听悟           | 听悟任务 API + WSS PCM 音频推流                              | AppKey、AccessKey ID、AccessKey Secret、语种 |

通义听悟已按上述专用协议适配。其他配置中的地址是协议示例，不代表已经为你选定供应商。**文本协议兼容不等于语音协议兼容**；除已适配的通义听悟外，其他专有鉴权、签名或 WebSocket 事件格式需要在 `electron/asr.cjs` 增加适配，不能仅替换 URL。所有服务端点拒绝明文 HTTP/WS、内嵌用户名密码和重定向。

保存配置后，在同一页面为当前课程单独授权“转录/选定材料/笔记”和“音频”。切换任何提供商配置会撤销旧授权并取消在途任务。文本测试按钮发送测试文本；听悟鉴权测试创建并结束测试任务，不发送录音，均可能产生调用费用。价格未接入，界面按调用次数及输出 token 上限控制请求，**不承诺金额上限**；实时语音费用应在供应商后台设置预算。

密钥使用 Electron safeStorage，在 Windows 上由当前系统账户保护。数据库与原始音频本身没有全盘加密。只有受控主进程读取密钥，界面快照不含密钥。

## 使用流程

1. 新建课程与课次，按需导入 PDF 课件、PDF 教材。只把当前选定页范围的文字提供给 AI；扫描 PDF 可预览，但不会伪造提取结果。
2. 开始录音，或导入 TXT/SRT 转录。课程右上角“…”中可导入 MP3/WAV，随后点击底部“补转写”。TXT 保留段号，不编造时间戳。
3. 半自动模式点击“提交本段”；录音中的未定稿尾部会登记待提交范围。自动模式按有效采集时钟登记 60 秒窗口，等待对应音频范围确认后提交。暂停时不累计采集时间。
4. 勾选转录段，点击“归入主题”，即可修正待归类或错误归属。纠错保留原转录修订，并标记受影响笔记。
5. 笔记支持 Markdown 编辑、阅读和约 800 ms 防抖保存。人工编辑后的 AI 更新进入候选；候选以主题为单位确认。过期候选必须重新生成，历史恢复会追加新版本。
6. 课程模板支持手动编辑、AI 起草、实际课次内容预览、独立复制。保存模板只影响之后创建的任务。
7. 导出读取固定笔记快照，生成 `notes.md`、`sources/` 和 `manifest.json`。来源含材料页或转录时间/段号。当前不自动复制 Markdown 本地图片附件，发现相关引用会明确拒绝导入/导出，不输出缺失附件的“成功包”。

开始录音和停止 AI 相互独立。本地模型安装后断网仍可转写；云端服务断开时音频仍保存，可在恢复服务后点“补转写”；补传只处理尚未确认的范围。恢复不会依靠文字相同去重，以免删掉老师的合理重复。

## 数据与恢复

默认目录为 `%APPDATA%/<应用名称>/library（开发运行名称为 lecture-notes-desktop，打包版本可能显示为听课笔记助手）`，内含 `app.db`、`courses/` 和 `lessons/`。如需备份，请退出应用后复制整个 `library` 目录。测试使用 `LECTURE_DATA_DIR` 指定隔离目录，不污染正式课程。

SQLite 当前以单个应用状态快照实现原子持久化，资源文件单独管理。写入采用临时文件、fsync、原子更名，成功后才显示保存完成。启动扫描遗留完整 WAV，补登记已经落盘但未登记的分片；中断任务变为可重试，避免未经确认的重复调用。

删除课程需要输入完整课程名，会撤销访问、取消在途任务并清理关联本地目录。应用外导出文件与供应商持有的数据无法由本地删除自动撤回。

## 构建与验证

```powershell
npm test                 # 核心规则、持久化、API 协议与故障注入测试
npm run build            # TypeScript 检查与界面构建
node tests/smoke.cjs      # Electron 窗口端到端测试，使用模拟麦克风
npm run pack             # Windows 解包目录
npm run dist             # Windows NSIS 安装包
```

端到端测试覆盖创建示例课、模拟整理、人工编辑保护、候选对照、PDF 导入与索引、模板起草预览、来源导出，以及录音暂停、继续、停止与尾部分片。测试数据及截图分别保存在 `.test-data/` 和 `artifacts/`。

详见 [实施说明](docs/implementation.md) 和 [验收清单](docs/acceptance.md)。此版是可运行、可配置 API 的试用实现；90 分钟真实课程、真实设备异常、真实供应商 5 秒转录与 20 秒笔记目标尚需现场验收。
