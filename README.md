# 听课笔记助手 · Windows / macOS 课程空间版

**v0.9.0** 支持用 DeepSeek、OpenAI Responses、Anthropic Messages 或自定义 Chat Completions 服务生成笔记。可以先从课件或教材建立章节骨架，再把选定页或课堂转录分批写入同一章。课堂工作区提供课件、教材、笔记、转录四个标签页。每次展开一页，切换时保留当前课堂的阅读位置、笔记编辑状态和转录选择。录音与整理任务在后台继续。

## 使用

1. 创建课程进入独立课程空间。左侧导入PDF、TXT或Markdown资料；Markdown相对图片会迁入受管附件，缺失会报告。扫描PDF无文字时仍需外部OCR。
2. 新建独立对话，选择资料章节、课程笔记或课堂转录后提问。切换对话保留历史、草稿和范围。可生成预习/复习资料，回答可另存主题或追加为候选。
3. 在“课堂记录”新建课堂，填写实际上课时间，从课程资料库选择课件、教材和目标笔记。同一笔记可关联多节课。
4. 用课堂标签切换资料、笔记和转录。点击笔记的页码或课堂来源会打开对应材料或转录位置。阅读来源与课件的 AI 起止页分别设置。
5. 课堂页顶部点击“整理课堂笔记”处理整课。转录区点击“选择时间段”，输入起止时间，再点击“选择范围”；可一次归入主题。无时间戳内容可按原始段落范围选择。**半自动**：用“整理所选内容”处理范围，用“整理当前讲解”提交录音边界，后台生成，录音继续。**自动·课后整理**：课堂中只录音转录，结束且完整后创建一次整课任务，可关闭“结束后自动整理”。导入完整TXT/SRT后，确认关联资料并点击“整课整理”。
6. 有转录缺口、收尾失败或待核对内容时显示待补齐。可补转写；明确选择不完整内容时，产物带缺失警告。长课自动分批、按主题归并，失败可重试未完成部分。
7. 人工编辑与版本冲突产生候选，确认前保留原笔记。课程页和课堂均可导出Markdown、来源和相对图片附件；公式保留可编辑文本。

关联课件后，在「课程课件」底部设定 AI 使用的起止页，在课堂工具栏选择「笔记结构」。按课件顺序整理时，系统用所选课件页的关键词检索教材。按教材顺序整理时，系统按命中教材页和已有小节组织内容，同时遵守课件选页范围。只有教材时，可按本次课堂讲解检索教材，并选择按教材或按课堂讲解整理。扫描 PDF 需要先提取文字才能用于检索。多节课共享同一份笔记时，采用候选会把新内容合入对应章节并保留已有正文和来源。

整理双语资料时，系统会用节号、标题词和课件正文对照教材小节，读取相邻的正文页，并过滤目录、索引等页面。模型按知识点合并续页，区分原始定义、教师举例和待核实内容。课件与教材的页码指文件中的 PDF 页。课堂短字幕各有独立引用，模型返回后映射回原句和时间。

整课整理时，如果课件有章节提纲，且转录中能定位老师结束概览、开始正文的转场，主要依据开场概述的提纲主题会收在「课堂任务 → 开场导读」中。正文候选照常在笔记页确认。

## 先建整章骨架，再补正文

在课程空间选择目标笔记，或进入已关联该笔记的课堂「笔记」页。选择课件或教材作为主资料，指定本章在文件中的实际起止页，生成并编辑骨架预览，核对标题、父子关系、次序和来源页后确认。此步骤可以在课前完成，无需转录。离线或模拟模式使用材料已有目录或可提取的标题；真实 API 模式通过课程文本授权和调用预算生成预览。

确认后，骨架绑定到这份笔记。课堂半自动模式可按时间段、段落或当前录音边界提交。也可从课程空间选择课件或教材页单独补充，或组合已选转录与资料页。默认匹配已有小节，也可指定一节。每批仅写入有本批证据的小节。相同提交复用任务，重叠提交跳过已经匹配的来源。未匹配的内容可重新选段、改选目标。人工编辑过的小节或整课任务先产生追加候选，确认时合入当下正文。多节课可选同一目标笔记，导出为一份带标题层级的 Markdown。

## API 与本地识别

在「API 与设置」中选择「真实 API」，再选文本提供商，填入该平台开放的模型 ID 与 API Key。保存配置后，为当前课程保存文字授权。选 OpenAI 时使用 [Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)，选 Anthropic Claude 时使用 [Messages API](https://platform.claude.com/docs/en/api/messages/create)。DeepSeek 使用其官方 Chat Completions 接口。其他兼容服务可填写完整 HTTPS 地址。各文本提供商的密钥由主进程使用系统加密存储，按提供商和服务地址的来源分别保存。语音识别可独立选择服务。


本地ASR可选SenseVoice和Qwen3-ASR，首次从设置下载模型；无需语音API密钥。关闭文本AI不影响本地识别。模型不随安装包分发，支持在设置查看下载状态和运行测试，详见[本地识别说明](docs/local-asr.md)。本地按12—20秒语段处理，不能宣称5秒实时字幕。

云端保留通用WSS转录及通义听悟。听悟需AppKey和AccessKey ID/Secret、项目权限及课程音频授权；不是百炼文本模型密钥。使用步骤和遗留任务处理见[听悟接入说明](docs/tingwu-integration.md)。其他厂商专有语音协议仍需对应适配器。

使用 DeepSeek 时，在「API 与设置」切换到「云端 API」并保存语音识别方式，工作模式选「真实 API」，语音提供商选「DeepSeek · 分段转写」。填写 DeepSeek 平台 API Key 并保存配置，然后为课程保存音频授权。若文本服务也使用 DeepSeek，可以在两个密钥字段填写同一个平台 Key。导入 MP3 / WAV 后，点击课堂底部「补转写」。应用会跳过已转写的音频范围，逐段提交剩余部分。接口自动识别语种，按音频时长计费。[DeepSeek 官方 ASR 指南](https://api-docs.deepseek.com/zh-cn/guides/asr)

课程空间底部单独配置文本单价、币种和金额预算。未知用量显示估算，未填预算不限制金额；已填预算但缺价格会暂停文本调用。该预算不包含ASR费用，实际以供应商账单为准。调用次数另行限制。

## 运行与构建

同一套源码支持 Windows 10/11 x64 与 macOS。macOS 已在 Apple Silicon 上验证；Intel 构建命令已提供，尚未实机验证。开发需 Node.js 22.12 或更新版本：

```bash
npm ci
node node_modules/electron/install.js
npm start
npm test
npm run test:desktop
npm run test:study
npm run test:chapter
npm run test:text-providers
npm run test:audio
npm run test:deepseek-asr
npm run pack
```

`npm run pack`、`npm run dist`默认构建当前系统版本。显式平台命令如下；正式构建建议在对应系统运行：

| 平台 | 免安装应用 | 安装/分发包 |
| --- | --- | --- |
| Windows x64 | `npm run pack:win` | `npm run dist:win`（NSIS） |
| macOS 当前架构 | `npm run pack:mac` | `npm run dist:mac`（DMG + ZIP） |
| macOS Intel | — | `npm run dist:mac:x64`（待实机验证） |

Windows 输出 `release-v0.9.0/win-unpacked/听课笔记助手.exe`，必须保留整个目录。Mac arm64 输出 `release-v0.9.0/mac-arm64/听课笔记助手.app`，可双击打开或通过 DMG 拖入“应用程序”。首次录音需允许麦克风权限；窗口关闭后可从 Dock 重开，Command+Q 退出。Mac 使用本地临时签名，未进行 Apple 公证；详见 [macOS 适配与验证](docs/macos-support.md)。

Windows 上可执行 `python scripts/package-delivery.py`生成源码、文档、免安装版和可用安装器的校验ZIP。测试数据、模型、密钥、开发依赖和二进制不提交Git。
