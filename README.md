# 听课笔记助手 · Windows / macOS 课程空间版

**v0.4.0**，采用纸白、墨黑、苔绿界面；支持按时间段/原始段落范围批量归类转录，顶部提供“整理课堂笔记”主操作（见[界面说明](docs/ui-redesign-v0.4.md)）。保留课程共享资料、多对话、预习复习与课后完整整理；延续大输出上限和可选 DeepSeek 思考模式。

## 使用

1. 创建课程进入独立课程空间。左侧导入PDF、TXT或Markdown资料；Markdown相对图片会迁入受管附件，缺失会报告。扫描PDF无文字时仍需外部OCR。
2. 新建独立对话，选择资料章节、课程笔记或课堂转录后提问。切换对话保留历史、草稿和范围。可生成预习/复习资料，回答可另存主题或追加为候选。
3. 在“课堂记录”新建课堂，填写实际上课时间，从课程资料库选择课件、教材和目标笔记。同一笔记可关联多节课。
4. 课堂四区支持阅读、范围设置、主题归属、编辑、录音和回听。浏览页与AI处理范围独立；四区可折叠/展开和调节大小。
5. 课堂页顶部点击“整理课堂笔记”处理整课。转录区点击“选择时间段”，输入起止时间，再点击“选择范围”；可一次归入主题。无时间戳内容可按原始段落范围选择。**半自动**：用“整理所选内容”处理范围，用“整理当前讲解”提交录音边界，后台生成，录音继续。**自动·课后整理**：课堂中只录音转录，结束且完整后创建一次整课任务，可关闭“结束后自动整理”。导入完整TXT/SRT后，确认关联资料并点击“整课整理”。
6. 有转录缺口、收尾失败或待核对内容时显示待补齐。可补转写；明确选择不完整内容时，产物带缺失警告。长课自动分批、按主题归并，失败可重试未完成部分。
7. 人工编辑与版本冲突产生候选，确认前保留原笔记。课程页和课堂均可导出Markdown、来源和相对图片附件；公式保留可编辑文本。

## API 与本地识别

设置中填写文本生成的Chat Completions兼容HTTPS地址、模型和密钥；每门课程显式授权后才发送选定资料。密钥通过系统加密存储保存在本机（Windows 账户保护 / macOS 钥匙串），不上传Git。模拟模式明确标注，不能用于内容质量验收。

本地ASR可选SenseVoice和Qwen3-ASR，首次从设置下载模型；无需语音API密钥。关闭文本AI不影响本地识别。模型不随安装包分发，支持在设置查看下载状态和运行测试，详见[本地识别说明](docs/local-asr.md)。本地按12—20秒语段处理，不能宣称5秒实时字幕。

云端保留通用WSS转录及通义听悟。听悟需AppKey和AccessKey ID/Secret、项目权限及课程音频授权；不是百炼文本模型密钥。使用步骤和遗留任务处理见[听悟接入说明](docs/tingwu-integration.md)。其他厂商专有语音协议仍需对应适配器。

课程空间底部单独配置文本单价、币种和金额预算。未知用量显示估算，未填预算不限制金额；已填预算但缺价格会暂停文本调用。该预算不包含ASR费用，实际以供应商账单为准。调用次数另行限制。

## 运行与构建

同一套源码支持 Windows 10/11 x64 与 macOS。macOS 已在 Apple Silicon 上验证；Intel 构建命令已提供，尚未实机验证。开发需 Node.js 22.12 或更新版本：

```bash
npm ci
node node_modules/electron/install.js
npm start
npm test
npm run test:desktop
npm run test:study
npm run test:audio
npm run pack
```

`npm run pack`、`npm run dist`默认构建当前系统版本。显式平台命令如下；正式构建建议在对应系统运行：

| 平台 | 免安装应用 | 安装/分发包 |
| --- | --- | --- |
| Windows x64 | `npm run pack:win` | `npm run dist:win`（NSIS） |
| macOS 当前架构 | `npm run pack:mac` | `npm run dist:mac`（DMG + ZIP） |
| macOS Intel | — | `npm run dist:mac:x64`（待实机验证） |

Windows 输出 `release-v0.4.0/win-unpacked/听课笔记助手.exe`，必须保留整个目录。Mac arm64 输出 `release-v0.4.0/mac-arm64/听课笔记助手.app`，可双击打开或通过 DMG 拖入“应用程序”。首次录音需允许麦克风权限；窗口关闭后可从 Dock 重开，Command+Q 退出。Mac 使用本地临时签名，未进行 Apple 公证；详见 [macOS 适配与验证](docs/macos-support.md)。

Windows 上可执行 `python scripts/package-delivery.py`生成源码、文档、免安装版和可用安装器的校验ZIP。测试数据、模型、密钥、开发依赖和二进制不提交Git。
